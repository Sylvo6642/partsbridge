# PartsBridge frontend

Next.js (App Router) + TypeScript + Tailwind CSS. A thin client for the FastAPI backend in `../backend`.
Designed with the impeccable skill: see `../PRODUCT.md`, `../.impeccable/surfaces/frontend.md` and `../DESIGN.md`.

```bash
cp .env.example .env.local   # Supabase URL + anon key (public), API URL
npm install
npm run dev                  # http://localhost:3000 (the API must run on :8010)
```
